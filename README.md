# Tic Tac Shuffle

A nested tic-tac-toe game. A 3x3 big board contains nine small 3x3 boards.

## How to play
- The game picks a highlighted small board at random.
- X plays one move there, then O replies in the same board. That is one round.
- After each round the game jumps to another undecided board at random, and X starts again.
- Win a small board (three in a row) to claim that cell of the big board.
- Claim three big cells in a row to win.
- Modes: vs Computer (Easy / Normal / Hard) or 2 Players.

## Run it
Open `index.html` in a browser. No build step, no dependencies.
